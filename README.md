# go-broken-line-checker# 🔍 Go Broken Link Checker

> Find Broken Links of Any Website in Seconds - Built with Golang

A fast, lightweight, and powerful tool to scan any website and detect broken links (404), dead links, and unreachable URLs.

### 🌐 Live Demo
**https://farimazhar.github.io/go-broken-link-checker/**

### ✨ Features
- ✅ **Full Website Scan:** Extracts all `<a href>` links from any given URL
- ✅ **Status Detection:** Checks HTTP status codes (200 OK, 404 Not Found, 500 Error)
- ✅ **Broken Link Report:** Separates OK vs BROKEN links with color-coded results
- ✅ **Lightning Fast:** Built with Golang concurrency - checks 20+ links in <5 seconds
- ✅ **Lightweight:** No database, no heavy dependencies

### 🛠️ Tech Stack
- **Backend:** Golang (Go 1.21+)
- **Parser:** goquery for HTML parsing
- **Frontend:** HTML, CSS, JavaScript
- **Hosting:** GitHub Pages

### 🎯 Who is this for?
- SEO Experts & Bloggers - to fix SEO issues
- Web Developers - to maintain website health
- QA Testers - to automate link testing

### 🚀 How to Use
1. Enter any website URL
2. Click "Check Broken Links"
3. Get instant report of all working and broken links
